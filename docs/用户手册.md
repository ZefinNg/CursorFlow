# CursorFlow 用户手册

CursorFlow 是一款轻量级的鼠标键盘活动统计工具：只统计「距离」和「次数」，**不记录任何按键内容、屏幕内容或个人文件**，所有数据只保存在你自己的电脑上。

版本 0.1.0 · 支持 Windows 10+ / macOS 12+ / Linux（X11）

---

## 1. 安装与首次启动

- **Windows**：运行安装包 `CursorFlow-x.y.z-win64.exe`，按向导完成安装。若杀毒软件提示"低级键盘钩子"，选择"允许"——CursorFlow 依赖系统钩子接口统计按键次数（详见 §7 隐私说明）。
- **macOS**：打开 `CursorFlow-x.y.z.dmg`，将应用拖入"应用程序"。首次启动系统会提示"辅助功能"权限：打开 **系统设置 → 隐私与安全性 → 辅助功能**，将 CursorFlow 加入并开启，之后重启应用即可开始统计。
- **Linux**：运行 `CursorFlow-x.y.z.AppImage`（X11 会话）。Wayland 会话受系统安全模型限制，应用会显示降级提示并停止采集，请切换到 X11 会话使用。

首次启动后 CursorFlow 立即开始统计，主窗口打开在"今日概览"页。

## 2. 今日概览（主页）

- **三张数据卡**：鼠标距离（米）、按键总数、活跃时长。鼠标距离按显示器 PPI 换算成物理米数。
- **光标轨迹动画**：跟随鼠标方向的粒子轨迹；可在 设置 → 显示 → 动画效果 中关闭。
- **今日 24 小时分布**：以热力格展示 0–23 时每个时段的距离与按键强度，悬停可查看具体数值。
- 页面底部常驻徽标：**"仅统计次数，不记录内容；数据仅保存在本地"**。
- 若采集被系统/安全软件拦截，页面顶部会出现红色横幅提示。

## 3. 历史趋势

- **近 7 天 / 近 30 天** 折线图：鼠标距离（左轴）与按键次数（右轴）双轴展示，悬停可查看某天明细。
- **今日 24 小时分布**热力图同样可在此查看。
- 数据需积累：使用一天后趋势图才会出现，此前显示空态引导。

## 4. 设置

### 通用
| 设置 | 说明 |
| ---- | ---- |
| 开机自启 | 登录后自动开始统计（默认关闭，可在托盘暂停） |
| 语言 | 跟随系统 / 中文 / English（切换后需重启应用生效） |
| 数据保留天数 | 30–3650 天，默认 365 天，超期数据在启动时自动清理 |

### 显示
- **主题**：深色 / 浅色 / 跟随系统。
- **字体大小**：90%–130% 无级缩放。
- **动画效果**：关闭后停止所有动效，进一步降低资源占用。

### 校准（让"米数"更准确）
1. 用尺子量出显示器对角线尺寸（英寸），填入"对角线尺寸"。
2. 填入屏幕分辨率（宽 × 高，即系统当前设置的分辨率）。
3. 应用自动换算 PPI 并立即生效；未校准时按 96 PPI 估算，界面会标注"估算值"。

### 导出
- 选择范围（近 7 / 30 / 90 / 365 天），点击 **导出 CSV** 或 **导出 JSON**，选择保存位置即可。
- CSV 含 UTF-8 BOM，Excel 直接打开中文表头不乱码；JSON 包含逐日汇总与 24 小时分布两个数组。
- 导出完成/失败会通过系统托盘气泡通知。

## 5. 托盘

关闭主窗口即最小化到托盘，统计继续进行。托盘菜单：

- **打开 CursorFlow**：重新打开主窗口。
- **暂停统计 / 恢复统计**：临时停止采集（暂停期间的活动不计入数据）。
- **今日：xx 米 · xx 键**：实时摘要。
- **退出…**：二次确认后退出并停止统计。

## 6. 数据与文件位置

| 内容 | 位置 |
| ---- | ---- |
| 统计数据库 | Windows：`%APPDATA%\CursorFlow\stats.db`；macOS：`~/Library/Application Support/CursorFlow/stats.db`；Linux：`~/.local/share/CursorFlow/stats.db` |
| 应用设置 | 系统标准配置存储（Windows 注册表 / macOS plist / Linux ini） |

- 卸载应用**不会**删除统计数据库；如需彻底清除，请手动删除上述文件。
- 备份：直接复制 `stats.db`（SQLite 单文件）即可。

## 7. 隐私说明

CursorFlow 的设计原则是**计数不记内容**：

1. **不记录按键内容**：键盘钩子只递增计数器，不捕获、不存储任何键名、文本或剪贴板内容；修饰键（Ctrl/Shift/Alt 等）的按住也不计为按键。
2. **不记录点击位置**：鼠标仅计算移动距离（像素→米），不保存坐标轨迹；点击只计左/右/中键次数。
3. **不联网**：应用无任何网络代码，数据不出本机。
4. **不上传、不遥测**：无崩溃上报、无使用统计回传。
5. **可随时暂停或清除**：托盘一键暂停；删除数据库文件即彻底清除全部历史。
6. **源码开放**：MIT 许可证，可自行审计或从源码构建。

## 8. 常见问题

**Q：杀毒软件报"键盘记录器"？**
CursorFlow 使用操作系统提供的低级钩子接口统计按键次数，这是少数杀软的常见误报特征。请将 CursorFlow 加入白名单；软件已开源，可自行审计。

**Q：鼠标距离和实际感受不符？**
默认按 96 PPI 估算。请在 设置 → 校准 中填入显示器对角线英寸数和分辨率，米数即按真实 PPI 换算。

**Q：休眠恢复后数据异常大？**
应用已在恢复时重置坐标基准，若仍出现跳变（如多屏切换瞬间），超出阈值的距离会被自动剔除；偶发异常不影响整体趋势。

**Q：macOS 提示无权限、数据一直为 0？**
按 §1 macOS 步骤授予"辅助功能"权限后重启应用。

**Q：Linux（Wayland）下提示无法采集？**
Wayland 禁止应用监听全局输入。请注销后在登录界面选择 X11/Xorg 会话。

**Q：想清空某天数据重新统计？**
当前版本暂不支持单日删除，可通过缩短"数据保留天数"或删除数据库文件重置。
