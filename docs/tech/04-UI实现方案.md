# CursorFlow UI 实现方案

> 关联 PRD：3.2 主界面仪表盘、3.3 托盘菜单、3.4 设置面板、8 界面设计原则
> 上游设计：[01-技术架构设计.md](01-技术架构设计.md)；数据来源见 [03-数据存储设计.md](03-数据存储设计.md)

## 1. 技术要点

- Qt Quick + Quick Controls 2（Fusion 风格基底 + 自定义材质），Qt 5.15.2。
- 图表自绘：`Canvas`（2D）绘制折线图与热力图，不引入 Qt Charts，控制包体并满足 <200ms 渲染目标（PRD 允许二选一）。
- 窗口：无边框 + 自定义标题栏；Windows 下可选 Acrylic/深色磨砂（`DwmSetWindowAttribute` + backdrop），失败降级为纯色深底。
- QML 与 C++ 绑定：`StatsController` 通过 `Q_PROPERTY ... NOTIFY` 暴露今日数据；`setContextProperty` 注入 `stats` / `settings` / `theme` 三个单例。

## 2. 页面结构

```
Main.qml
├── Sidebar（图标导航：概览 / 历史 / 设置）
├── StackView
│   ├── DashboardPage.qml     # 今日概览
│   ├── HistoryPage.qml       # 趋势图 + 热力图
│   └── SettingsPage.qml      # 四组设置
└── PrivacyDialog.qml         # 首启隐私声明（阻断式）
```

### 2.1 DashboardPage（PRD 3.2）
- 顶部三张 StatCard：鼠标距离（m/km 自适应单位）、按键总数、活跃时长；数字用 `NumberAnimation` 滚动更新。
- 卡片下方实时动态区：`ParticleTrail` 粒子轨迹（PRD 可选开关），实现为 32 个粒子跟随最近鼠标速度向量衰减运动；`animationsEnabled=false` 时不创建实例。
- 底部小时热力图 24 格。

### 2.2 HistoryPage（PRD 3.2）
- TrendChart：双序列折线（距离/按键，左右双 Y 轴），Canvas 绘制：
  - 数据源 `queryDaily(from,to)`；
  - 悬停最近点显示 tooltip（日期 + 数值），`MouseArea` + 定位浮层；
  - 7/30 天 Tab 切换，`Canvas.requestPaint()` 重绘（预期 <200ms，数据 ≤30 点）。
- HeatmapGrid：24 格矩形，颜色映射 5 档透明度（主题色 blue-violet），悬停显示"HH:00 – 距离/按键数"。

### 2.3 SettingsPage（PRD 3.4）

| 分组 | 控件 | 存储键（QSettings） |
|------|------|---------------------|
| 通用 | 开机自启 Switch | `general/autostart`（Win: 注册表 Run；macOS: SMLoginItemSetEnabled；Linux: .desktop 自启目录） |
| 通用 | 语言 ComboBox（中/英） | `general/language`（切换后提示重启） |
| 通用 | 数据保留天数 SpinBox | `general/retentionDays` |
| 显示 | 主题三选一（深/浅/跟随系统） | `display/themeMode` |
| 显示 | 字体大小 Slider | `display/fontScale`（0.9–1.3） |
| 显示 | 动画开关 | `display/animationsEnabled` |
| 校准 | 屏幕英寸 + 分辨率输入 → 只读 PPI 结果 | `calibration/diagonalInch`、`calibration/ppi` |
| 导出 | 范围选择 + CSV/JSON 按钮 | — |

设置项变更即写 `AppSettings`（QSettings 后端），校准项同步通知采集线程更新 DPI。

## 3. 托盘菜单（PRD 3.3）

`QSystemTrayIcon` + QMenu（主线程）：

```
打开 CursorFlow            → show/raise 窗口
暂停统计 / 恢复统计         → captureWorker.pause()/resume()，图标切换状态
────────────
今日：2.3 km · 12,450 键   → 只读项，由 statsSaved/分钟级定时刷新
────────────
退出…                      → QMessageBox 确认（PRD 二次确认）→ flush 后退出
```

- 关闭窗口 = 隐藏到托盘（不退出）；仅托盘菜单退出。
- 图标状态：正常采集（彩色）/ 已暂停（灰）/ 采集失败（灰+叹号）。

## 4. 主题系统（PRD 8）

`Theme.qml` 单例，按 `themeMode` + 系统主题解析出 token：

```qml
// 深色（默认）
bg:        "#0F1117"          // 主背景
surface:   "#1A1D27"          // 卡片
primary:   "#6C7BFF"          // 蓝紫（渐变起点）
secondary: "#3DD6C3"          // 青绿（渐变终点）
text:      "#E8EAF2"
textDim:   "#8A90A5"
// 浅色模式对应翻转；磨砂失败时 surface 用不透明色
```

- 渐变卡片：`LinearGradient`（primary→secondary，低饱和，135°）。
- 字体：Inter（打包内嵌，中文回退到系统 UI 字体：微软雅黑/PingFang SC/Noto Sans CJK）；字号乘以 `fontScale`。
- 图标：Material Design Icons 子集，以内嵌 SVG 资源（qrc）引入，仅打包使用到的图标。
- 动效：页面切换 `StackView.push` 自带过渡 + 数字滚动 + 图表渐进描线；`animationsEnabled=false` 时统一禁用。

## 5. 国际化（PRD Phase 3）

- 所有 UI 文案使用 `qsTr()`；`i18n/CursorFlow_zh_CN.ts`、`_en.ts`；Linguist 翻译后发布 `.qm` 打进 qrc。
- 语言切换：`QTranslator` 加载 + 提示重启（QML 已挂载文本重翻译成本高）。
- 数字单位遵循本地化格式（千分位），距离单位保持 m/km。

## 6. 状态与空态

| 状态 | 展示 |
|------|------|
| 首启未同意隐私 | 阻断式 PrivacyDialog（同意后才注入钩子） |
| 采集暂停 | 卡片右上"已暂停"标签 + 托盘灰色图标 |
| 采集失败（权限/杀软） | 顶部横幅提示原因 + 引导（macOS 跳辅助功能设置） |
| 无历史数据 | 空态插画 + "数据正在积累中" |
| 今日 0 活动 | 数字显示 0，热力图全灰 |

## 7. 性能实现约束

- Dashboard 属性刷新节流 ≥1s（Controller 侧 timer 合并 NOTIFY）。
- HistoryPage 懒加载：首次切换到该页才请求数据。
- Canvas 图表一次 requestPaint 完成全量重绘，避免逐点动画残留。
- ParticleTrail 仅在前台 + 开关开启时运行；窗口隐藏即暂停 `Timer`。
- 图片/SVG 全部走 qrc，避免运行时磁盘 IO。

## 8. 测试要点

- 主题三模式 + 磨砂失败降级截图比对。
- 7/30 天切换、悬停 tooltip 数值与数据库一致。
- DPI 缩放 100%/150%/200% 布局不破版。
- 动画关闭后 CPU 占用回落（任务管理器对比）。
- 中英切换后布局无截断（按钮最长文案宽度校验）。
