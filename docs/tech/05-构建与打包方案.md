# CursorFlow 构建与打包方案

> 关联 PRD：5 技术选型、非功能需求（安装包 < 15 MB）、9 开发计划
> 上游设计：[01-技术架构设计.md](01-技术架构设计.md)

## 1. 构建工具链

| 项 | 选型 | 说明 |
|----|------|------|
| 构建系统 | CMake ≥ 3.16 | Qt 5.15 官方支持 |
| 生成器 | Ninja | 快速增量构建 |
| 编译器 | MSVC 2019 (Win) / Clang (macOS) / GCC 9+ (Linux) | C++17 |
| Qt | 5.15.2，静态编译核心模块 | 包体目标的关键 |
| CI | GitHub Actions 三平台矩阵 | 见 §5 |

## 3. CMake 要点

```cmake
cmake_minimum_required(VERSION 3.16)
project(CursorFlow VERSION 0.1.0 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_AUTOMOC ON)
set(CMAKE_AUTORCC ON)

find_package(Qt5 5.15.2 REQUIRED COMPONENTS Quick QuickControls2 Sql Svg)

qt5_add_resources(QRC_FILES assets/assets.qrc)   # 图标/字体/qm/qml 全部入 qrc

add_executable(CursorFlow WIN32 MACOSX_BUNDLE
    ${SOURCES} ${QRC_FILES})

target_compile_definitions(CursorFlow PRIVATE
    QT_DEPRECATED_WARNINGS APP_VERSION="${PROJECT_VERSION}")

# Win: 静态链接 CRT，减小依赖
if(MSVC)
    target_compile_options(CursorFlow PRIVATE /MT)
endif()
```

- `WIN32`/`MACOSX_BUNDLE` 保证无控制台窗口 / 正确的 app bundle 结构。
- 仅链接 4 个 Qt 模块（Quick、QuickControls2、Sql、Svg），GUI/Network 等不引入。

## 4. 包体控制（目标 < 15 MB）

| 手段 | 预期收益 |
|------|----------|
| Qt 静态库 + 按模块裁剪编译（configure 时 `-skip` 无关模块，`-release -static`） | 核心大头 |
| `qt_import_qml_plugin` 显式声明用到的 QML 插件，避免 qml 目录整体拷贝 | 数 MB |
| Qt Quick 2D Renderer 不启用；不含 QtWebEngine/Charts/Multimedia | 免除最大依赖 |
| LTO（`CMAKE_INTERPROCEDURAL_OPTIMIZATION=ON`）+ strip | 10–20% |
| 字体仅打包 Inter Regular/Medium（不打包全字重）；图标 SVG 而非 PNG | < 300 KB |
| UPX（仅 Windows，可选，需评估杀软误报风险——PRD 风险项，默认不开） | 视情况 |

预估：静态 Qt Quick 最小集约 10–13 MB（Win），满足目标；macOS DMG 因框架签名结构略大，必要时用 thin binary。

## 5. 打包（CPack）

```cmake
set(CPACK_PACKAGE_NAME "CursorFlow")
set(CPACK_PACKAGE_VERSION ${PROJECT_VERSION})
if(WIN32)
    set(CPACK_GENERATOR "NSIS")
    set(CPACK_NSIS_ENABLE_UNINSTALL_BEFORE_INSTALL ON)
    # 开机自启勾选项写入注册表 Run 键
elseif(APPLE)
    set(CPACK_GENERATOR "DragNDrop")           # DMG
    set(CPACK_DMG_SLA_DIR ${CMAKE_SOURCE_DIR}/packaging/macos/sla)
else()
    set(CPACK_GENERATOR "AppImage")
endif()
include(CPack)
```

| 平台 | 产物 | 注意点 |
|------|------|--------|
| Windows | `CursorFlow-Setup-x64.exe`（NSIS） | 代码签名（PRD 风险：杀软误报）signtool 后置 |
| macOS | `CursorFlow.dmg` | Developer ID 签名 + notarization；Info.plist 声明辅助功能用途说明 |
| Linux | `CursorFlow-x86_64.AppImage` | 内嵌 .desktop + 图标；依赖较少的 X11 库随包携带 |

## 6. CI（GitHub Actions）

- 触发：tag `v*` 发布构建 + push 主干每日构建。
- 矩阵：`windows-latest`（MSVC）、`macos-13`（Xcode）、`ubuntu-20.04`（容器内安装静态 Qt 5.15.2，如 `aqtinstall` 拉取 + 自编译静态 Qt 缓存）。
- 步骤：configure(Ninja) → build → ctest → cpack → 上传 artifact；tag 时创建 GitHub Release 并签名。
- 静态 Qt 缓存（ccache + Qt build 目录 artifact）以缩短 CI 时长。

## 7. 质量门禁

- clang-format（.clang-format 随仓库）+ clang-tidy（bugprone/performance 集）CI 检查。
- ASan/MSan 构建目标（`-DCURSORFLOW_SANITIZE=address`）供开发期使用；发布前跑一轮内存泄漏检测（PRD Phase 3）。
- ctest 单元测试：距离计算、存储 UPSERT、活跃推断（不依赖真实输入设备）。

## 8. 本地开发快速命令

```bash
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build
cpack --config build/CPackConfig.cmake -B build/pack
```
