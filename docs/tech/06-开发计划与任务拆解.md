     └─ 2.1 ─ 2.2 ─┤↑

## 6. 风险应对计划（落实 PRD §10）

| 风险              | 影响        | 应对动作                               | 落点任务     |
| --------------- | --------- | ---------------------------------- | -------- |
| 杀软误报低级钩子        | 用户无法安装/运行 | 代码签名；误报样本提交白名单；README 提供源码构建路径     | 5.4      |
| macOS 授权失败致采集为空 | 功能不可用     | 启动检测 `AXIsProcessTrusted` + 图文引导页  | 4.5      |
| 高 DPI 距离偏差      | 数据不准      | 默认 96 DPI 估算 + 手动校准；校准前 UI 标注"估算值" | 4.4      |
| 用户误解键盘记录        | 信任问题      | 首页常驻"仅统计次数，不记录内容"徽标；隐私声明明确         | 2.4, 3.1 |
| 静态 Qt 包体超标      | 违反非功能需求   | M1 起每周 CI 产物体积监控，超 13MB 预警         | 1.1, 5.4 |
