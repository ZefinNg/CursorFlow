# CursorFlow 数据采集模块设计

> 关联 PRD：3.1 数据采集、3.5 隐私与安全、10 风险与对策
> 上游设计：[01-技术架构设计.md](01-技术架构设计.md)

## 1. 模块职责

在独立线程中通过平台全局钩子捕获输入事件，完成四类统计：

1. 鼠标移动物理距离（米）
2. 键盘按键次数（仅计数，不记录内容）
3. 鼠标左/右/中键点击次数
4. 滚轮滚动步数

并负责异常过滤（跳变剔除）、活跃时长推断、向 DataManager 提交增量。

## 2. 核心类设计

```cpp
// 增量缓冲区：原子计数，回调线程写，flush 读
struct DeltaBuffer {
    std::atomic<double>  distancePx{0.0};    // 像素距离累加
    std::atomic<uint32_t> keyPresses{0};
    std::atomic<uint32_t> leftClicks{0};
    std::atomic<uint32_t> rightClicks{0};
    std::atomic<uint32_t> midClicks{0};
    std::atomic<int32_t>  scrollSteps{0};    // 带符号
    std::atomic<int64_t>  lastInputMs{0};    // 最近一次输入时间戳（活跃推断）
    void reset();                            // flush 后清零
};

class InputCaptureWorker : public QObject {
    Q_OBJECT
public:
    bool start();          // 装载 IPlatformHook，注册 3s flush 定时器
    void pause();          // 托盘"暂停统计"：挂起钩子但不卸载
    void resume();
signals:
    void deltaReady(DeltaSnapshot delta);   // 每 3 秒跨线程提交
};
```

`DeltaSnapshot` 为普通 POD 结构（各计数值 + 时间区间），经排队信号投递到主线程，避免共享可变状态。

## 3. 各平台钩子实现

### 3.1 Windows（MVP 优先实现）

```cpp
HHOOK mh = SetWindowsHookEx(WH_MOUSE_LL,   MouseProc, nullptr, 0);
HHOOK kh = SetWindowsHookEx(WH_KEYBOARD_LL, KbdProc,  nullptr, 0);
```

- 低级钩子回调运行在安装线程的消息循环中 → 采集线程需运行 `QThread::exec()` 并处理 Windows 消息（`MsgWaitForMultipleObjects` 或让 Qt 消息循环派发 `WM_*`）。
- 回调必须**快速返回**（超时系统会移除钩子），回调内只做：读取坐标 / 判断按键 → 原子自增。距离计算推迟到 flush，或回调内只累加 ΔX/ΔY。
- `WM_MOUSEWHEEL` 的 `wheelDelta`（±120 一格）换算为滚动步数。
- 双击不重复计数：直接按 `WM_LBUTTONDOWN` 次数统计。
- 键盘：只统计 `WM_KEYDOWN/WM_SYSKEYDOWN` 次数，**不读取键值内容**，仅判断是否为修饰键以执行 PRD 的"组合键不重复计数"规则（详见 4.2）。

### 3.2 macOS

- `CGEventTapCreate(kCGSessionEventTap, kCGHeadInsertEventTap, kCGEventTapOptionListenOnly, ...)`，只监听不改写。
- 监听 `kCGEventMouseMoved / LeftMouseDown / RightMouseDown / OtherMouseDown / ScrollWheel / keyDown`。
- 权限：需"辅助功能"授权；启动时用 `AXIsProcessTrusted()` 检测，未授权则发引导（PRD 风险对策）。授权后事件 tap 才有数据，无需重启进程（重新创建 tap 即可）。

### 3.3 Linux（X11）

- XInput2：`XISelectEvents` 订阅根窗口的 `XI_RawMotion / XI_RawButtonPress / XI_RawKeyPress`。
- `XI_RawMotion` 携带 raw 值（valuator），累加位移。
- MVP 仅支持 X11；Wayland 环境检测到 `WAYLAND_DISPLAY` 时提示降级为"仅托盘 + 手动记录"或提示用户切换 X11 会话。

## 4. 关键算法

### 4.1 鼠标距离：像素 → 物理

```
单步距离(px)  = sqrt((x2-x1)² + (y2-y1)²)
有效判断      : 距离 ≤ 2 × max(屏幕宽, 高)     // PRD: 超过对角线2倍视为跳变
物理距离(米)  = Σ像素距离 / DPI × 25.4mm / 1000
DPI           = 用户校准值 或 96（默认）
```

- 校准输入：屏幕对角线英寸数 + 分辨率 → `PPI = sqrt(w²+h²)/inch`，1px = 25.4/PPI 毫米（PRD 3.4 校准项）。
- 多屏：使用**虚拟桌面全局坐标**（Windows 的 `GetSystemMetrics(SM_XVIRTUALSCREEN)` 等），避免坐标系切换导致负跳变；跳变剔除规则同样适用。

### 4.2 键盘计数规则（PRD：不含修饰符重复计数）

| 场景 | 计数 |
|------|------|
| 普通按键按下 | +1 |
| 按住不放（OS 自动重复） | +1（只统计首次 keydown，重复事件丢弃） |
| Ctrl+C 组合键 | +1（C 键计数；Ctrl 按下/释放不计数） |
| 纯按 Ctrl | +1（修饰键单独按下仍计一次） |

实现：维护 `lastKeyCode` 与自动重复标记；Windows 下用 `KBDLLHOOK_STRUCT.flags & LLKHF_UP` 区分按下/释放，用 `dwExtraInfo` 之外的重复检测（连续相同 vk 且无中间 up）过滤。

### 4.3 活跃时长推断

- `lastInputMs` 记录最近输入时间；任一输入事件刷新。
- 每 3 秒 flush 时：若 `now - lastInputMs ≤ 120s`（5 分钟空闲阈值可配置），本次区间记为活跃，累加进当日 `active_minutes`（以秒累计、分钟展示）。

### 4.4 滚动步数

- Windows：`wParam 高字 signed` / `WHEEL_DELTA(120)` → 步数（带方向）。
- macOS：`CGEventGetIntegerValueField(event, kCGScrollWheelEventDeltaAxis1)`。
- 存储与统计采用**绝对值累加**（PRD 要求），方向信息不落库。

## 5. 异常与边界处理

| 场景 | 处理 |
|------|------|
| 远程桌面/投屏坐标跳变 | 距离 > 2×屏幕对角线 → 丢弃该步进量（PRD 3.1） |
| 系统休眠/恢复 | 挂起时暂停采集（监听 `QSessionManager`/电源广播），恢复后重置"上次坐标"防止大跳变 |
| 钩子被系统移除 | Windows 下检测回调不再触发的超时保护；自动重装一次并上报 UI 状态 |
| 跨天零点 | flush 时按事件发生时间归属到对应日期；跨零点时拆分到两天（简化实现：以 flush 时间归属，误差 ≤3s 可接受） |
| 暂停统计 | 托盘暂停 → `pause()` 停止累加（钩子保留），恢复后重置坐标基准 |

## 6. 隐私约束（实现层强制，对应 PRD 3.5）

1. **键盘**：代码中不存在保存键值的路径 —— 回调里只 `++counter`，键值仅用于判断修饰键/重复，不进入任何缓冲区、日志或数据库。
2. **进程白名单**：不记录按键发生的窗口/进程（超出 PRD 范围）。
3. **首次启动隐私声明**：`main.cpp` 在装载钩子前弹出同意页，`QSettings` 记录 `privacyAccepted=true` 后才调用 `start()`；拒绝则仅展示空仪表盘 + 提示。
4. **审计点**：Code Review 检查项 —— 任何 `GetKeyNameText` / 字符映射类 API 均不得出现在采集路径。

## 7. 测试要点

- 单元：距离计算（含跳变剔除）、DPI 换算、活跃推断（模拟时间戳序列）。
- 平台手测脚本：录制宏模拟鼠标轨迹（已知长度）验证误差 < 5%；键盘连打/组合键/长按场景计数正确。
- 边界：休眠恢复、多屏拖拽、远程会话、系统时间回拨（跨天归属）。
