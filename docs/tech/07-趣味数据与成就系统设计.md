# CursorFlow 趣味数据与成就系统设计

> 关联 PRD：3.8 数据趣味化与社交分享（M5，任务 7.x）
> 上游设计：[01-技术架构设计.md](01-技术架构设计.md)；数据表变更见 [03-数据存储设计.md](03-数据存储设计.md)；UI 落点见 [04-UI实现方案.md](04-UI实现方案.md) §2.6

## 1. 目标与边界

- 将今日/累计的鼠标距离、按键次数换算为可感知的生活场景类比，驱动趣味卡片、成就弹窗与每日简报三类 UI 呈现。
- **隐私红线不变（PRD 3.5）**：全部换算仅在本地完成；"分享"为生成图片由用户手动发布，应用不联网、不上传任何数据。
- 性能预算：规则库常驻内存 < 20 KB；单次选条计算为 O(n) 线性遍历（n ≈ 30 条），< 1 ms。

## 2. 类比引擎（FunFactsController，C++）

### 2.1 规则库数据结构

规则库以 JSON 随 qrc 内置（`assets/funfacts.json`，任务 7.1 落地），每条规则：

```json
{
  "id": "track_laps",
  "metric": "distance",          // distance（米）/ keys（次）
  "scope": "today",              // today 今日口径 / total 累计口径
  "category": "sport",           // sport 运动健康 / geo 地理旅行 / daily 日常物品 / game 娱乐彩蛋
  "style": "sport",              // sport 运动系 / art 文艺系 / geek 极客系（PRD 3.8.3 过滤用）
  "refValue": 400,               // 参照物量值（米 或 次）
  "text": "相当于绕标准 400 米跑道跑了 %1 圈",
  "textEn": "Equal to %1 laps around a 400 m track"
}
```

参考规则库（与产品示例图一致，落地时按此扩充至 ≥ 12 距离条 + ≥ 10 按键条）：

| 题材 | 距离类参照 | 按键类参照 |
|------|-----------|-----------|
| 运动健康 | 400m 跑道圈数；爬楼 3m/层；1km≈50 大卡→苹果个数 | 每键≈0.5 卡→俯卧撑个数；《致爱丽丝》≈300 键/遍 |
| 地理旅行 | 京沪 1318 km 路程百分比；赤道 40075 km 圈数；地月 38 万 km 往返 | 《三体》≈90 万字/套→本书数；A4 纸≈2000 字符/页→页数 |
| 日常物品 | 足球场 7140 ㎡（轨迹宽 1mm）；围巾（1cm≈10 像素移动） | 每 1000 键≈1ml 墨水→瓶数；轴体寿命 5000 万次→个数 |
| 娱乐彩蛋 | 《我的世界》16×16 区块数；《星际争霸》农民挖矿趟数 | LOL"所有人聊天"（平均 50 次/局）→局数 |

### 2.2 选条策略

- 输入：当日/累计距离（米）、按键数；用户风格（`fun/style`）与自定义参照物。
- 过滤：`metric` 匹配口径 → `style` 匹配模板（无匹配时回退全部）→ 排除已达成的成就对应条目（避免剧透）。
- 计算 X = value / refValue，**仅保留 1 ≤ X ≤ 999 的候选**，并按"最具体"排序取第一条：
  - 距离类取 log(X) 最接近 1（即 X ≈ 10）者优先，按键类同理；
  - 全部越界时（数据过小/过大）取最接近区间的条目并保留 2 位小数。
- 自定义参照物（`fun/customRefName` + `fun/customRefValue`）动态合成一条 `style` 无关规则参与候选，命中时优先展示。
- 暴露接口：`Q_PROPERTY QString todayFunFact` / `QString totalFunFact`（NOTIFY，随 statsSaved 刷新），QML 直接绑定。

### 3.2 触发与存储

- 存储：SQLite 新表 `achievements`（见 03 号文档 §2 增补），`id TEXT PRIMARY KEY, unlocked_at TEXT`；幂等：INSERT OR IGNORE，已获得不重复弹窗。
- 触发链路：`DataManager::statsSaved` → `AchievementController::check()`（比对累计/单日阈值）→ `unlocked(Achievement)` 信号 → QML `AchievementDialog` 弹窗（同风格深色卡片 + 徽标 + 等级色）。
- 查询：`QVariantList achievements()`（全部定义 + 已获得状态与时间），供成就列表 UI。

### 3.3 一键截图分享（任务 7.4）

- 实现：成就卡片 QML Item 调 `grabToImage(callback)`（离屏渲染，与显示状态无关）→ 回调中 `QImage` 交付 C++ `AchievementController::saveShareImage(QImage)`。
- 双通道（均为本地动作）：① 保存到 `QStandardPaths::PicturesLocation/CursorFlow/`（带日期文件名，返回路径提示）；② 写入系统剪贴板 `QClipboard::setImage()`。
- 图片内容：成就徽标 + 名称 + 数据 + CursorFlow 品牌 footer；**不含任何用户输入内容**（6.3 日志红线同源）。

## 4. 每日简报（任务 7.5）

- 生成逻辑：按当日距离 + 按键 + 活跃时长映射强度分档（轻松 / 适中 / 爆肝，阈值见代码表），从对应档位模板池随机取一条，`qsTr("今天你的鼠标游荡了 %1，%2").arg(...)` 合成。
- 呈现位置：仪表盘标题下方简报条；每日首次进入页面生成并缓存当日结果（`meta` 表记 `brief_date`），当日不重复抖动。
- 文案模板全部走 `qsTr()`，en/zh 翻译同步补充。

## 5. 设置项（AppSettings 新增键，04 §2.3 同步）

| 键 | 含义 | 默认 |
|----|------|------|
| `fun/style` | 类比风格：0 运动系 / 1 文艺系 / 2 极客系 | 0 |
| `fun/customRefName` | 自定义参照物名称 | 空（禁用） |
| `fun/customRefValue` | 自定义参照物量值（米或次，随名称输入的指标自动判定） | 0 |

## 6. 测试要点

- 选条策略边界：数据为 0（不展示卡片）、X 越界回退、自定义参照物优先级、风格过滤回退。
- 成就：跨日累计达阈值仅弹一次（重启不重复）；`INSERT OR IGNORE` 幂等；连续天数断签重置。
- 截图：高 DPI 下 grabToImage 分辨率正确；剪贴板写入成功；保存路径无权限时降级提示。
- i18n：三条链路（类比/成就/简报）文案随语言切换翻译完整。
