# 鼠标键盘活动统计工具 PRD（Product Requirements Document）

## 1. 项目概述
一款轻量级的桌面统计工具，运行于 Windows/macOS/Linux，实时记录并可视化每日鼠标移动距离（单位：米/千米）和键盘按键次数（含左键/右键/滚轮）。强调 UI 美观、低资源占用、隐私安全。

## 2. 目标用户
- 程序员、设计师、重度办公用户，希望了解自己日常操作强度
- 对个人生产力数据感兴趣的极客
- 需要长时间使用电脑的健康监测用户（配合休息提醒）

## 3. 核心功能需求

### 3.1 数据采集（后台常驻服务）
- **鼠标移动距离**：通过全局钩子获取每次鼠标位置变化，计算欧氏距离并累加。过滤掉因多屏切换、远程桌面导致的异常跳变（超过屏幕对角线长度 2 倍视为无效）。
- **键盘按键次数**：统计所有按键按下次数（不含组合键修饰符重复计数）。仅累计总数，不记录具体按键内容，保证隐私。
- **鼠标点击次数**：分别统计左键、右键、中键点击次数。
- **滚轮滚动量**：统计滚轮滚动步数（向上为正，向下为负，绝对值累加）。
- **数据持久化**：每小时自动写入 SQLite 数据库，按天分表存储。

### 3.2 主界面仪表盘
- **今日概览**：大数字显示当日鼠标距离、按键总数、活跃时长（基于输入间隔推断）。
- **历史趋势**：折线图展示过去 7/30 天的日统计数据。
- **小时热力图**：24 小时方格热力图，颜色深浅表示该小时的操作密集程度；仪表盘与历史趋势页的分布卡片右上角均支持放大/缩小（6.5）：放大后带动画扩展至填满窗口剩余区域并切换为逐小时柱状图，缩小恢复原占比。
- **实时动态**：鼠标移动轨迹的轻微粒子动画（可选开关，减少 GPU 消耗）。

### 3.3 托盘菜单
- 隐藏/显示主窗口
- 暂停/恢复统计（临时停止采集）
- 查看今日统计摘要
- 退出程序（带二次确认）
- 左键单击图标即显示并激活主窗口（M4 6.4 增补）

### 3.4 设置面板
- 通用：开机自启、语言（中文/英文）、数据保留天数（自动清理旧数据）
- 显示：主题（深色/浅色/跟随系统）、字体大小、动画开关、关闭窗口行为（每次询问/最小化到托盘/退出程序）
- 关闭主窗口时询问"退出程序 / 最小化窗口"并可勾选"记住选择"，已记住的选项可在设置中修改（M4 6.4 增补）
- 校准：屏幕尺寸（英寸）与分辨率 → 自动计算每像素对应物理距离，提高鼠标距离精确度
- 导出：将统计数据导出为 CSV / JSON
- 关于：软件版本号、Qt 版本、构建信息、开源许可（MIT / Qt LGPL 声明）与项目链接

### 3.5 隐私与安全
- 所有数据仅存储在本地 SQLite，不上传云端。
- 键盘仅统计次数，不记录字符序列。
- 首次启动弹出隐私声明，用户同意后才开始采集。

### 3.6 首次启动引导
- 首次启动（隐私声明同意后）展示引导向导：欢迎与隐私要点 → 屏幕尺寸设置（对角线英寸 + 分辨率，与设置页校准项一致，可跳过、跳过则按 96 PPI 估算）。
- 完成后明确提示"屏幕尺寸信息可随时在 设置 → 校准 中修改"。
- 引导完成或跳过后记录标记，后续启动不再出现。

### 3.7 自定义标题栏（M4 6.6 增补）
- 移除系统原生标题栏（含系统最小化/最大化/关闭按钮），采用与主界面一致的自绘标题栏，深/浅色主题联动。
- 左侧展示软件 Logo 与名称；右上角提供最小化、最大化/还原、关闭三个窗口控制按钮，按钮风格与主题一致。
- 标题栏空白区域支持拖拽移动窗口（保留系统贴靠行为），双击切换最大化/还原。
- 窗口四边与四角支持拖拽缩放，保留原有最小尺寸约束；最大化时禁用缩放。
- 关闭按钮沿用 3.4 的关闭窗口行为（每次询问 / 最小化 / 退出程序）。

### 3.8 数据趣味化与社交分享（M5 增补，任务 7.x）

**核心价值主张**：将抽象的鼠标移动距离、键盘敲击次数转化为用户可感知、可共鸣的生活场景类比（如"今天相当于绕跑道跑了 8 圈"），提升工具的趣味性和社交分享欲望，从而增加用户粘性和自发传播。详细规则库与引擎设计见 [07-趣味数据与成就系统设计.md](tech/07-趣味数据与成就系统设计.md)。

#### 3.8.1 趣味类比展示
- 仪表盘展示"趣味换算"卡片：内置类比规则库按当前数据挑选最贴切的一条，格式"相当于 XXX"；数值适中不夸大（避免"0.01 圈"或"300 万圈"）。
- 规则库分四类题材：**运动健康**（绕跑道圈数、爬楼层、苹果热量、俯卧撑、弹《致爱丽丝》）、**地理旅行**（京沪线路程百分比、绕赤道圈数、往返月球、《三体》字数、A4 纸页数）、**日常物品**（足球场、织围巾、墨水瓶、键盘轴体寿命）、**娱乐彩蛋**（《我的世界》区块、《星际争霸》挖矿、LOL"所有人聊天"）。
- 距离类与按键类各自独立换算；今日与累计两种口径分别使用。

#### 3.8.2 动态成就系统
- 累计数据达到特定阈值时弹出同风格成就卡片弹窗（如"马拉松选手"累计 42.195 km、"键盘钢琴家"累计敲击 10 万次），每项成就仅触发一次。
- 成就分等级（青铜/白银/黄金），阈值表可持续扩充。
- 成就卡片支持一键截图分享：保存 PNG 到系统图片目录并复制到剪贴板，由用户手动发布到社交平台；应用自身不联网（3.5 隐私红线不变）。

#### 3.8.3 个性化模板
- 用户可选择类比风格模板：**运动系 / 文艺系 / 极客系**，对应不同规则库子集与文案语气。
- 支持自定义参照物：用户录入自己的生活数据（如"我家的客厅长度是 5 米"），类比引擎用自定义参照物生成换算。

#### 3.8.4 每日简报
- 每天首次查看仪表盘时生成一句"今日工作强度"文案，例如："今天你的鼠标游荡了 1.2 公里，相当于在办公室走神散步了 15 分钟。"
- 文案由模板库按当日数据强度分档即时生成，随语言切换翻译。

## 4. 非功能需求
- **性能**：后台进程 CPU 占用 < 1%（空闲时），内存 < 50 MB。
- **响应速度**：主窗口打开 < 500ms，图表渲染 < 200ms。
- **兼容性**：Windows 10/11，macOS 12+，Ubuntu 20.04+。
- **安装包大小**：< 15 MB（静态编译 Qt 核心库）。

## 5. 技术选型

| 层面 | 技术 | 理由 |
|------|------|------|
| 编程语言 | C++17 | 高性能、系统级 API 调用 |
| UI 框架 | Qt 5.15.2 (QML + Quick Controls 2) | 原生质感、流畅动画、跨平台一致，LTS 版本稳定 |
| 全局钩子 | Windows: `SetWindowsHookEx` / macOS: `CGEventTap` / Linux: `XInput2` | 标准系统 API，稳定可靠 |
| 数据存储 | SQLite via Qt SQL module | 零配置、单文件、嵌入式 |
| 图表库 | Qt Charts 或自定义 Canvas 绘制 | 轻量，无需第三方 JS 引擎 |
| 构建工具 | CMake + Ninja | 跨平台构建标准 |
| 打包工具 | CPack (NSIS for Win, DMG for Mac, AppImage for Linux) | 原生安装体验 |

## 6. 架构设计
┌─────────────────────────────┐

│        QML UI Layer         │

│  (Dashboard, Settings, etc) │

├─────────────────────────────┤

│      C++ Controller         │

│  (DataManager, ChartModel)  │

├─────────────────────────────┤

│    InputCapture Thread      │

│  (Platform-specific hooks)  │

├─────────────────────────────┤

│       Storage Layer         │

│  (SQLite via Qt SQL)        │

└─────────────────────────────┘
- **InputCapture**：独立线程运行，使用锁保护共享计数器，每隔 3 秒将增量提交给 DataManager。
- **DataManager**：负责聚合、定时写入数据库、对外提供查询接口（信号槽通知 UI 更新）。
- **UI**：QML 绑定 C++ 对象属性，实现数据驱动刷新。

## 7. 数据模型（SQLite）
sql

CREATE TABLE daily_stats (

date TEXT PRIMARY KEY,          -- '2026-10-30'

mouse_distance_m REAL DEFAULT 0,

key_press_count INTEGER DEFAULT 0,

left_click_count INTEGER DEFAULT 0,

right_click_count INTEGER DEFAULT 0,

scroll_steps INTEGER DEFAULT 0,

active_minutes INTEGER DEFAULT 0

);

CREATE TABLE hourly_stats (

id INTEGER PRIMARY KEY AUTOINCREMENT,

date TEXT NOT NULL,

hour INTEGER NOT NULL CHECK(hour BETWEEN 0 AND 23),

mouse_distance_m REAL DEFAULT 0,

key_press_count INTEGER DEFAULT 0

);
## 8. 界面设计原则（UI 美化）

- **主题**：默认深色磨砂玻璃效果（Acrylic），支持浅色模式。
- **配色**：低饱和度渐变色（蓝紫→青绿），字体使用 Inter 或系统 San Francisco。
- **布局**：顶部大数字卡片（今日数据），中间双折线图（距离+按键），底部热力图。
- **动效**：页面切换平滑过渡，数字滚动更新，鼠标悬停图表显示详情。
- **图标**：统一使用 Material Design Icons 或 Font Awesome（内嵌 SVG）。

## 9. 开发计划

### Phase 1：MVP（4 周）
- 完成 Windows 平台全局钩子 + 数据采集
- 实现 SQLite 存储与基础查询
- 搭建 QML 主界面，显示今日数字（无图表）
- 托盘图标 + 最小化功能

### Phase 2：可视化增强（2 周）
- 集成 Qt Charts 绘制历史折线图、热力图
- 添加设置面板（主题切换、开机自启）
- 完善 macOS / Linux 钩子适配

### Phase 3：打磨与发布（2 周）
- 国际化（中/英）
- 导出 CSV
- 性能优化、内存泄漏检测
- 打包安装程序，编写用户文档
